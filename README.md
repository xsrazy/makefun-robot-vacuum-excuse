A single-line entry for the make.fun bounty "The Robot Vacuum's Funniest Excuse": the excuse a robot vacuum gives for missing one spot, in at most 120 characters. The entry blames bureaucracy, not the battery — the dust in that corner unionized, elected a spokesperson, and now the poor vacuum needs a permit to enter.

## Run

```sh
python3 main.py
```

This writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) as bytes with no trailing newline.
